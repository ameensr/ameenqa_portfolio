## Customise content

Open the admin UI: [admin/](admin/) (or `https://ameensr.github.io/ameenqa_portfolio/admin/`).

1. Edit sections (experience, certificates, photo paths, resume link, etc.)
2. **Download config.js**
3. Replace the root `config.js` in this repo
4. To change the photo: replace `profile.jpg` / `profile.webp` in the repo root
5. Commit and push — GitHub Pages will update the live site

Drafts can also be saved in the browser (local only).
